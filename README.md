This repository contains a **Prompt Engineering Portfolio** demonstrating prompt design, iteration, temperature control, Chain-of-Thought prompting, Few-Shot prompting, and Responsible AI practices. Through practical examples, the project highlights how prompt structure, context, and instructions influence the quality, accuracy, and creativity of Large Language Model (LLM) outputs. It also explores common limitations such as hallucinations and bias, along with strategies to mitigate them.

**Tools Used:** Claude Sonnet 4 (Claude.ai)
**Skills Demonstrated:** Prompt Engineering, Prompt Optimization, AI Reasoning, Output Evaluation, and Responsible AI.
